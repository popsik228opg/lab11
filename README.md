# Лабораторное занятие №11 — «Работа с файлами»

Дисциплина: «Языки и методы программирования», ГУУ, факультет «Прикладная информатика».
Выполнил: Бубнов Александр, группа ПИ2-1. Преподаватель: Авдеев В.С.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `src/FileDemo.java` | Часть 1: создание `example.txt`, запись, чтение, дозапись, построчное чтение |
| `src/Book.java` | Класс книги (название, автор, год, жанр), проверка данных, преобразование в строку файла и обратно |
| `src/BookStorage.java` | Чтение и запись `library.txt` (`BufferedReader`, `FileWriter`, UTF-8) |
| `src/LibraryApp.java` | Часть 2: консольное меню «Библиотека книг» |

## Возможности «Библиотеки книг»

1. Добавить книгу (дозапись в конец `library.txt`).
2. Показать все книги.
3. Удалить книгу по названию (все точные совпадения, после подтверждения).
4. Поиск книг по автору без учёта регистра (самостоятельная работа).

Формат хранения — одна книга в строке:

```
Название;Автор;Год;Жанр
```

Символ `;` внутри полей запрещён. Если файла нет, список считается пустым, файл создаётся при добавлении первой книги.
Повреждённые строки пропускаются с предупреждением, ошибки доступа к файлу выводятся пользователю.

## Запуск

Нужен JDK 17 или новее.

```bash
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out FileDemo      # часть 1
java -cp out LibraryApp    # часть 2
```

В IntelliJ IDEA: создать проект (JDK 17), скопировать файлы в папку `src`, запустить `FileDemo` или `LibraryApp`.
Если в консоли Windows вместо русских букв «кракозябры», выполните `chcp 65001` перед запуском.

Файлы `data/example.txt` и `library.txt` создаются в рабочей папке запуска.
